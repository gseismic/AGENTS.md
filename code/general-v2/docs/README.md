# 开发文档

本文件是开发文档首页模板，面向开发者和 Agent。应用到目标项目时，依据实际内容完善本页，维护开发说明、阅读顺序、常驻必读清单和分类导航。

## 阅读顺序

1. 首先检查项目根目录的 `GOAL.md`；存在时阅读全文，理解用户目标。缺失时继续工作，不擅自创建。
2. 强烈推荐阅读根目录 `README.md`，理解项目用途、安装和使用方式。
3. 开始开发任务或恢复上下文时，阅读本页及下方所有常驻必读文档的全文；按任务需要从导航继续阅读专题材料。

## 常驻必读

当前模板尚未登记目标项目的设计文档。采用模板时，将这段说明替换为项目当前有效的重要总体设计、架构边界和长期约束文档清单。

每项包含文档标题、用途、当前有效状态和相对链接。总体设计默认位置为 `docs/design/OVERVIEW.md`；项目已有稳定路径时沿用。只登记已存在的文档，历史或已废弃设计通过相关文档保留追溯入口。

## 开发与验证

采用模板时，按实际配置填写开发环境要求、依赖安装、本地开发、构建与测试方法，以及必要的环境变量说明。命令应可复核，未验证的步骤明确标注；不写入密钥等敏感值。

## 文档导航

以下列出规范中的约定位置，供登记导航时参考，不表示文件已经创建。采用模板时，按实际存在的文档将相关项整理为可打开的链接；Markdown 链接相对于本文件所在的 `docs/` 目录解析。

| 分类 | 项目根相对路径 | 登记内容 |
| --- | --- | --- |
| 总体设计 | `docs/design/OVERVIEW.md`，或项目已有稳定路径 | 当前有效的总体设计，同时列入上方常驻必读清单。 |
| 专题设计 | `docs/design/INDEX.md` | 设计文档索引，标明用途、状态和替代关系。 |
| 计划与结果 | `docs/plans/INDEX.md` | 实施计划、对应结果和当前状态。 |
| 已知问题 | `docs/KNOWN-ISSUES.md` | 当前已确认问题及详情入口。 |
| 后续工作 | `docs/TODOS.md` | 待评估或尚未完成工作的索引。 |
| 项目交接 | `docs/HANDOFF.md` | 接手时需要核实的进度、工作区状态和未完成事项。 |
| 侦察、Review、代码解释与逆向规格 | `docs/research/`、`docs/reviews/`、`docs/explanations/`、`docs/reverse-spec/` | 按项目实际内容登记相关文档或分类入口。 |
