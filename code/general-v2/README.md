# general-v2

基于 `general` 扩展的通用代码项目 Agent 工作规范模板，保留原有目标保护、计划、验证、Git、问题跟踪和交接规则，补充项目启动与开发文档阅读约定。

| 文件 | 用途 |
| --- | --- |
| [AGENTS.md](./AGENTS.md) | 放在目标项目根目录，保存稳定工作规则和固定文档入口。 |
| [docs/README.md](./docs/README.md) | 开发文档首页模板，供目标项目登记常驻必读文档、开发说明和分类导航。 |

## 使用方法

1. 将规范应用到目标项目根目录；已有 `AGENTS.md` 时合并适用规则，保留项目专属约束，并根据实际情况调整固定文档路径。
2. 需要开发文档首页时，采用或合并首页模板，按目标项目已有内容完善说明和链接。模板中的建议路径不表示文件已经存在，不预先创建空目录、空设计或 `GOAL.md`。
3. 将当前有效的重要总体设计登记为“常驻必读”。总体设计默认入口为 `docs/design/OVERVIEW.md`；已有稳定路径时沿用，在首页登记，专题设计清单由 `docs/design/INDEX.md` 维护。
4. 开始工作时首先阅读 `GOAL.md`（若存在），强烈推荐阅读根目录 `README.md`；开发任务或恢复上下文时，必须阅读开发文档首页及其中的常驻必读文档，再按需展开相关上下文。

根目录 `README.md` 面向项目使用者；开发文档清单、当前设计和进度在开发文档中维护。`AGENTS.md` 只规定固定入口与工作方式，日常开发不把这些变动内容写进规范。

具体步骤见 [优先阅读顺序](./AGENTS.md#优先阅读顺序)、[新项目启动](./AGENTS.md#新项目启动) 和 [接手已有项目](./AGENTS.md#接手已有项目)。
